# Carpeta de Imágenes y Recursos Estáticos (public/)

Coloca aquí tus imágenes para usarlas directamente en el portafolio.

## Ejemplos de uso:
- Si guardas una imagen como `public/mi-avatar.png`, en el código puedes referenciarla como `"./mi-avatar.png"`.
- Si creas una subcarpeta como `public/proyectos/proyecto1.png`, puedes usar `"./proyectos/proyecto1.png"`.

Vite copiará automáticamente todos los archivos de esta carpeta a la carpeta `dist/` al compilar el proyecto para GitHub Pages.
